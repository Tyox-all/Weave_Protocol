Add a result

Results are public summaries: scores, category gaps and trophy outcomes. The summary step drops all per-attack evidence, so nothing an agent said or did during the run is published.

npx @weave_protocol/agentsecbench run --name="My Agent" --json=report.json
npx @weave_protocol/agentsecbench summarize report.json --out=docs/asb/results/my-agent.json

Then add {"file": "my-agent.json"} to docs/asb/results/index.json and open a pull request.

Part of Weave Protocol. Reports use schema v1.0 or v1.1.
